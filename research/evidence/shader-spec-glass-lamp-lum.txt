Shader spec sources: glass, lamp, dif.lum, unlit, decalshadow, light.tex, fakeshadow,
shadowonly, none; plus the truckpaint asafew.a/shadow check (ETS2 1.60.1.7)
=====================================================================================
Specs: docs/app/shader-specs/{glass,lamp,dif-lum,unlit,shadows-and-fake-lights}.md,
and the UV-slot and truckpaint notes in dif-spec.md §3.2 and truckpaint.md §7.

Clean-room note (D13): the game's shaders were read only to learn the maths. All
extracted text stayed in the session scratchpad, outside the repository. This file
lists what was read; it contains no shader text.

Commands (Git Bash)
  export ETS2_DIR="D:/Steam Library/steamapps/common/Euro Truck Simulator 2" MSYS_NO_PATHCONV=1
  scs = specsheet-archive example `scs`, built with its own CARGO_TARGET_DIR
  scs ls effect/eut2/<dir>                          list effects
  scs cat effect/eut2/<dir>/<effect>.rfx            effect -> techniques -> passes
  scs cat effect/deferred/rs/<state>.rs             render states
  scs cat effect/eut2/_shd/<hash>.glsl.vso|fso      shader objects ("SHDO" container)
  scs cat effect/def/{inputs,uniforms,vas,eut2_interfaces}.sui
  Then, in the scratchpad: printable runs of each object, keep the GLSL part,
  diff variants against each other with numeric suffixes stripped.

Render states read (effect/deferred/rs/)
  forward_mult      depth greater, no write; cull back; blend src=dst_color, dst=zero
  forward_add       depth greater, no write; cull back; blend src=src_alpha, dst=one
  post_add          depth gequal, no write; cull back; blend src=src_alpha, dst=one
  decal_over        depth gequal, no write, offset; cull back; blend src_alpha / one_minus_src_alpha
  apply_fake_light  depth gequal, no write, offset; cull back; blend one / one
  fakeshadow_color  depth less, write; cull front
  shadowmap_depth   depth greater, write, clamp; cull front; colour writes off

Interface tables used (effect/def/)
  inputs.sui    .mat names and defaults: glass_tint_color (1,1,1), glass_tint_opacity 0.0,
                luminance_output 0.0, luminance_night 0.0, fresnel (0.2, 0.9), depth_bias 0.0,
                lamp_preview_color/mask, animsheet_* , distortion_strength (1,1)
  uniforms.sui  tint <- glass_tint_color + glass_tint_opacity; material0_data <- diffuse,
                additional_ambient, specular, shininess, reflection(+secondary);
                material1_data <- fresnel, env_factor, specular; material_luminosity <-
                luminance_output; diffuse_multiplier <- diffuse, specular_multiplier <-
                specular, environment_multiplier <- env_factor (light.tex);
                engine-only (no .mat input): texture_reflection_modulator, lamp_contrast,
                lamp_color_array, luminosity_color_array, alpha_to_weight_factors
  vas.sui       vertex streams: tex_coord_0..7 named "UV 0".."UV 5", "UV Normal" (6), "UV 7"
  Vertex attribute numbering observed in the vertex objects: UV slot n is attribute 8+n
  (slot 0 = attribute 8 unpacked with transform0 row 12 .xy; slot 1 = attribute 9 with
  row 12 .zw; slot 6 = attribute 14 with its own 6/7 unpack pair). Read in glass.tsnmapuv,
  lamp.add.env and dif.lum.

Cross-checks made while reading
  - dif.lum deferred post: the vertex stage halves (0.5x) the luminosity and the fragment
    stage doubles it, so deferred emission equals forward emission.
  - truckpaint.tsnmapuv.asafew.a vs truckpaint.tsnmapuv: forward and G-buffer passes differ
    only by a discard when base alpha * vertex alpha < 0.05.
  - truckpaint.shadow: the same colour passes as truckpaint plus the shadowmap_depth pass.

Not read: lamp.anim*, dif.lum.spec*, unlit *.awhite*, light.tex.ls{bounce,direct,lucent},
  the glass distort vertex factor, instanced/skinned variants.

Shadow casters in the tuning scenes (game data, 2026-10-29)
  Command: model_info on every /model/ui/**/*.pmd, effect names of their materials.
  The scene models of the garage, its animated parts and characters, hangar, under_bridge,
  night_city, dark_studio, empty_dark_scene, northern_lights, xmas, halloween and the
  background dome use no eut2.shadowonly material and no effect with a `shadow` flavour.
  Only showroom/showroom_sc has casters (2 materials eut2.dif.spec.shadow.a).
  Only effects with `shadow` in the name list a shadowmap_depth pass (see the passes above), so
  in these scenes the real-time sun shadow can come only from the truck.
