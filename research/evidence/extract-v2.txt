Extraction of game (HashFS v2) archives, plain files (D19, docs/formats/mods.md)
==============================================================================

Subject: three archives of the test install (ETS2 1.60.1.7), read only,
extracted to a scratch folder outside the game, its home and the
repository, checked, then deleted. No file contents quoted.

Commands (Windows 11):
  ETS2_DIR=<install> mod_extract --list "<install>/<archive>.scs"
  ETS2_DIR=<install> mod_extract "<install>/<archive>.scs" <scratch>/<archive>
  ETS2_DIR=<install> extract_check "<install>/<archive>.scs" <scratch>/<archive>
Names come from the archive's own listings (walked from the root), then
from every path of the mounted game (`game_paths`) for entries no listing
names. extract_check compares every file the listing gives:
  - with Vfs::read, where the mounted game reads the path from this
    archive (Vfs::locate);
  - with this archive's own Archive::read, where a higher archive
    overrides the path (Vfs::read rightly differs there, or may);
  - unnamed files with Archive::read_entry of the hash in their name.
