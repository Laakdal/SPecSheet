Truck material survey: shine and reflection attributes (materials task)
=======================================================================

Command (ETS2 1.60.1.7, install opened read-only):
  ETS2_DIR=<game> cargo run --release -p specsheet-data --example material_survey

Every distinct .mat referenced by a /vehicle/truck .pmd look, grouped by effect
family. Per family: each numeric attribute's count and min/max per component,
and up to 4 example sources per texture slot. Then the first 25 materials whose
base texture path contains "chrom" or "metal".

Observations (Confirmed, from the output below):
- Only effects containing `env` carry `env_factor`, `fresnel` and a
  `texture_reflection` cube (/material/environment/*_reflection*.tobj).
- Typical chrome (`dif.spec.weight.add.env`, chrome_plain/chrome_c bases):
  diffuse 0.214, env_factor 0.977, shininess 70, specular 1.0, fresnel (1, 1),
  reflection cube vehicle_reflection.tobj. The diffuse is dark on purpose; the
  look comes from the environment term.
- shininess ranges 0..650 for most families (one outlier at 90000).
Meaning of each attribute in the shader: not established here (see the
effect GLSL in effect.scs; never commit shader text).
