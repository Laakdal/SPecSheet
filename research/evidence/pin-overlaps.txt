Exterior pin overlaps on every truck's starting configuration
==============================================================

Command (ETS2 1.60.1.7, install opened read-only):
  ETS2_DIR=<game> cargo run --release -p specsheet-research --example pin_dump

Builds each truck's starting configuration with the app's pin rules (F5,
docs/app/hotspots.md) and lists the exterior pins (wheel sub-pins excluded)
that land within 5 cm of another.

Observations (Confirmed for our rules, from the output below):
- 26 trucks, 1,629 exterior pins, 27 overlapping pairs.
- 12 are `r_deflector` with itself: its scene-table entry is double_sided
  with an offset x of 0, so the mirrored pin lands on the original. The
  game's builder mirrors every double_sided entry the same way and merges
  nothing (F5, rea pin-attributes §5-8), so it draws the pair too
  (Hypothesis: on top of each other, so it looks like one pin).
- The other 15 are different slots whose base locators plus offsets nearly
  coincide (e.g. f_intake_chs and badge on the Scania S, 4 mm apart; badge
  sets a/b/c on DAF and Volvo). They follow from the data, not from a rule.
Not established: the game's model search order (cabin first is ours) and the
default of use_non_wheel_pin_data_from_model; a REA run is planned.
