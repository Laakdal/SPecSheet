How each fact was established
  - Forward 3e383530 (add.env): one UV interpolant from texcoord0 (vertex 417b3c58); base rgb x
    doubled vertex colour; specular power 1024 * over.r^2, specular intensity over.g, gate
    switch over.b > 0.5; no .mat diffuse/specular/shininess/additional_ambient constants;
    reflection = cube x (3 * mask.r * reflection modulator) x Schlick fresnel x saturated
    ambient-alpha; output alpha 1.
  - Forward 80a70fb0 (paint) vs 3e383530: only the albedo differs: paint mask (texture_mask_1.r
    x 4, saturated) lerps base rgb towards base rgb x material_diffuse.
  - G-buffer 954a7ea2 (= baked.spec's): same albedo, power, intensity and gate; zero emittance,
    ka 0. Paint G-buffer 419739b0 adds the same paint lerp.
  - Post pass a59ca572 (post_add.rs: blend src_alpha/one, depth gequal, no write, back cull):
    the reflection of the forward pass, with the normal from the G-buffer and the visibility
    from the diffuse light buffer alpha.
  - Uniform table: material_diffuse <- input.diffuse; fresnel (float4) <- input.fresnel;
    texture_reflection_modulator has no input (engine).
  - Interface table: eut2.baked.spec.add.env and .paint = colour, normal, position, texcoord0.
