What it does (observed)
-----------------------
It clones the part's material onto the effect "eut2.truckpaint" with a set of
flags, then binds textures and writes four colour constants.

1. Opt-out. Some materials skip every paint feature:
   - the original material passes a check FUN_14042e920 (Unknown), or
   - it passes FUN_14042e8c0 (Unknown) and its four floats at material +0x70
     equal (-1, -2, -3, -4).
   Such a material gets plain eut2.truckpaint: no colormask, airbrush,
   flipflake or altuv flag.
2. Flags, otherwise (record = argument 2):
   - airbrush    = record byte +0xa1;
   - flipflake   = record byte +0xa0, named "flipflakeuv" when argument 4
                   is set and "flipflake" otherwise;
   - colormask   = the record's mask path (+0x08) is non-empty AND neither
                   flipflake nor airbrush is set;
   - altuv       = argument 3.
   So airbrush and colormask never combine, colormask and flipflake never
   combine, and airbrush and flipflake can combine.
3. Flags carried over from the original material: shadow, skinned, the flag
   named by "asafew.a" (Unknown which), and one more flag that FUN_1408d0810
   reads from the original material (Unknown which).
4. The flag set is converted to an RFX effect; on failure the messages above
   are logged and the part keeps its material.
5. Textures (the new material has 8 slots, matched by slot name):
   - if colormask or airbrush: the record's mask path (+0x08) goes into
     the slot texture_paintjob;
   - if flipflake: the record's second path (+0x88) goes into
     texture_flakenoise;
   - if argument 5 is a non-empty path: it replaces texture_base.
6. Four colour constants (vec4) are written to the material at +0xf0, +0x100,
   +0x110, +0x120:
   - without flipflake: (r+0x20..0x28, 0), (r+0x2c..0x34, 0),
     (r+0x38..0x40, 0), (r+0x44..0x4c, 0): four colours, w = 0;
   - with flipflake: (r+0x6c, r+0x78, r+0x7c, r+0x70),
     (r+0x60, r+0x64, r+0x68, r+0x74), (r+0x50..0x5c), (r+0x44..0x4c, 0):
     the fourth colour is shared; the first three pack flake/flip values.
   Which paint-job attribute sits at which record offset is set by the
   caller (next run: FUN_1408d1e70).
7. If the original material passed FUN_14042e920, the new material's +0x70
   is set to (-1, -2, -3, -4).
