Vehicle light hookups (flares): which ones truck models name, and whether they resolve
=====================================================================================

Command (ETS2 1.60.1.7, install opened read-only):
  ETS2_DIR=<game> cargo run --release -p specsheet-research --example flare_survey

Scans the exterior model of every truck accessory (all trucks, deduplicated
by path), collects each locator's hookup string, and resolves the `flare.*`
ones against the units in /unit/hookup/vehicle/flare/*.sii (classes
flare_vehicle, flare_blink, beacon_vehicle; specsheet-data::flare).

Observations (Confirmed, from the output below):
- 49 distinct `flare.*` hookups; 47 resolve. The two that do not,
  flare.vehicle.lblinkerl_ledl and flare.vehicle.rblinkerl_ledl (4 locators
  each, one model), name no unit; the folder defines lblinkr_ledl and
  rblinkr_ledl. Hypothesis: a naming slip in the game data; such lights get
  no flare.
- Every glow model a resolved unit names exists. Units ending in _noflr /
  _nofl / intlight_bck.* have no model: they only light (no glow sprite).
- Every glow model is under /model/flare/ (uniform_white, _red, _orange,
  _cold_white and their _amplified/_low/_dimmed forms).
- Light types seen: low_beam, high_beam, parking, brake, reverse,
  left_blinker, right_blinker, aux, beacon, electrics.
- Beacons also use flare_only.vehicle.beacon.blink_l/_r and
  light_only.vehicle.beacon.blink_l/_r, which are not in this folder (not
  resolved here).
Not established: how the engine draws a flare (eut2.flare, spec pending),
and which light types a scene's vehicle_lights_on switches on (light mask
0xd01b, rea-ui-scene-update.txt).
