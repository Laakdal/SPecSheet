2. 8.3 short-name aliases stop an extraction (Confirmed)
-------------------------------------------------------
Without --skip-existing both builds stopped on MAN TG3 with
  Io { path: ".../_30_3__/_____/_____#_/______/__#_____/___##/______~1.dds",
       source: Os { code: 80, kind: AlreadyExists } }
`dir /x` of that folder (short name, then long name):
  ______~1.DDS _________.dds
  ______~3.DDS _________~1.dds
The earlier file `_________.dds` holds the alias `______~1.DDS`. The
collision suffix `~N` gave a later file the name `______~1.dds`, which
Windows resolved to that alias, so create_new failed. With --skip-existing
the same 24 files were skipped instead of written.


3. After the fix
----------------
New build with the alias check, no --skip-existing, MAN TG3:
  "7558 entries, 4519 named, 3039 unnamed"
  "wrote 7551 files (5397.8 MB), 3039 under _unnamed/, 1409 renamed, 0 skipped, 0 unreadable"
  exit 0, 54 s. 7,551 files = 7,558 entries minus 7 directory listings.
Content check (sha256 values as a multiset, _renamed.txt left out):
  old run (section 1) 7,527 files, fix run 7,551 files
  only in old: 0   only in fix: 24
So the fix adds exactly the 24 files that were skipped and changes no
content; 24 paths differ because the stepped-around names shift their `~N`.
