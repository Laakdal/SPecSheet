## E2 (Confirmed): how the default interior is selected
- The cabin's defaults[] lists one interior. Example: highline.sii -> interior/cab_s_high_black_dark.sii;
  each Volvo FH 2024 cabin -> slp_dyn / gt_dyn / gt_xl_dyn / gt_xxl_dyn.
- The desktop presets select their own interior via `vehicle_accessory : .interior { data_path: ... }`:
  scania_s_2016 -> interior/cab_s_high_smartdash_advanced_v8.sii; volvo_fh_2024 -> interior/gt_xl_fh16.sii.

## E4 (Confirmed): the full interior model is a separate frame, not needed for the exterior view
- Scania interior/model.pmd AABB x[-0.487,1.870] matches the ext model's frame. Its origin is the cabin locator
  interior_s (eu_part, -0.683,2.705,-1.862); the UK model_uk.pmd AABB x[-1.870,0.487] matches interior_s1 (uk_part, +0.683,...).
- Size: Scania full interior model.pmg is 4.28 MB vs ext stock.pmg 0.50 MB (cabin 1.64 MB); Volvo gt_xl.pmg is
  5.59 MB vs ext 0.36 MB. The ext model is 8-15x smaller. Scania ext uses 2 materials (dif.spec.rfx and
  shadowonly); the full model uses 39 materials and 31 locators.

## E5 (Confirmed geometry): interior addon locators are duplicated on the cabin in cabin space
Cabin cab_s_high.pmd carries toyhang, toyseat, toystand, toyac, toybed, toybig_*, set_dashbrd, set_lglass*,
curtain_f, intlight_*, l_pillow, drv_plate, codrv_plate, swheel(_uk).
Check: interior model toyhang (0.683,0.318,-0.681) + interior_s (-0.683,2.705,-1.862) = (0.000,3.023,-2.543),
vs cabin toyhang (-0.007,3.023,-2.567). Within 3 cm. The current addon placement at cabin locators stays valid.

## E6 (Hypothesis): right-hand-drive interiors are separate units flagged left_hand_traffic: true
219 of 438 units have left_hand_traffic: true. 203 pair with an EU unit by filename (uk_ prefix or _uk suffix);
16 do not (MAN tgx_euro6 uses a _uk_ infix, e.g. alu_uk_xl_2019.sii). Pair by data instead: same suitable_for[],
same ext_model and ext_look, and left_hand_traffic matching the drive. Cabin defaults[] list only the EU unit.
The ext_interior locator is in a part visible in both variants, so the placement is the same for both drives.
