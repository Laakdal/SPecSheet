Shader spec sources: the vehicle fake shadow (docs/app/shader-specs/fake-shadow.md), ETS2 1.60.1.7
=================================================================================================
Clean-room note (D13): shaders read only to learn the maths; extracted text stayed in the session
scratchpad. This file lists what was read; it contains no shader text.

Effects (scs ls/cat effect/deferred/def_apply_fake_shadow; glsl technique)
  def.apply.fake.shadow.rfx       defgeom  apply_fake_shadow  e019bee5453af07c7e76edda834105c6 517857d8d2e422e35ce307b4e1bfcffa
  def.apply.fake.shadow.dist.rfx  defgeom  apply_fake_shadow  e019bee5453af07c7e76edda834105c6 606755806d0697787147283d46b96a2d
  effect/deferred/rs/apply_fake_shadow.rs: blend src dst_color, dst zero (multiply); cull front.
  Vertex stage: a volume in clip space, its z pinned to w when it lies beyond the far plane, and
  the screen position packed for the fragment stage.
  Fragment, both: eye position from G-buffer depth and the view ray; projector matrix; colour
  texture sample; light-buffer outputs diffuse (1-I, 1-I, 1-I, sat((1-I)^2)) and specular
  ((1-I)^2, ..., 0).
  Fragment, .dist only: jitter texture tiled every 64 px; depth bias from it; 4 taps of a
  one-channel distance map at +-jitter.xy and +-jitter.zw; per-tap scene fade-out on the receiver
  distance scaled by the colour texture's red, counted only behind the occluder; average; light
  fade-out on the receiver depth; times colour alpha and the light's diffuse red.
  Uniforms named (engine-set): light projection matrix, light diffuse, smap light and scene
  fade-outs, smap texture size; samplers jitter, light rgba texture, light r_0 texture, G-buffer.

Contour pass (shadows-and-fake-lights.md section 3)
  eut2.fakeshadow: one pass "fakeshadcol", writes 0.5 + 0.5 * uncorrected clip z, depth less with
  write, cull front. 155 truck models use eut2.fakeshadow (effect-usage-survey.txt).

Ambient occlusion exists separately (not specified yet): effect/deferred/def_ssao/
  def.ssao.{zfetch,zreduce,compute,spatial_denoise_a,spatial_denoise_b,temporal_denoise,upscale}.rfx;
  executable strings name it GTAO (gtao_config0/1, "GTAO ao noisy", bent normals, env visibility),
  the setting r_ssao and the uniform ao_apply_params.

The UI shadow model (game data, 2026-10-29)
  def_grep accessory_chassis_data ui_shadow over /def/vehicle/truck: all 164 chassis of all 26
  trucks set ui_shadow (70 distinct .pmd files), next to extended_shadow_texture (.tobj),
  extended_shadow_intensity, extended_shadow_fadeout_start/length and
  extended_shadow_shared_model_variant. Example, volvo.fh_2024 chassis 4x2:
    ui_shadow = /vehicle/truck/volvo_fh16_2012/ui_shadow/ui_shadow_4x2.pmd
    extended_shadow_texture = /vehicle/truck/volvo_fh16_2012/shadow_4x2.tobj, intensity 1.0,
    fadeout_start 10, fadeout_length 0.
  model_info on ui_shadow_4x2.pmd: one piece of 4 vertices, a flat quad at y = 0.0003,
  x -2.18..2.18, z -4.06..4.29; 13 looks (default, gt, gt_xl, gt_xxl, fh16, fh16_xl, fh16_xxl,
  fh16_780(_xl/_xxl), fh16_750(_xl/_xxl)); material eut2.dif.over with diffuse (1,1,1),
  specular 0, texture_base = the same shadow_4x2.tobj, clamp_to_border, mip_filter none.
  The chassis class attribute table (exe, class ptr 0x141d1fd70) stores ui_shadow at +0x400 as
  a path, next to the shadow keys at +0x378..+0x3d0. What chooses the look is not read; the
  FH16 2012 cabins all use look "default".
