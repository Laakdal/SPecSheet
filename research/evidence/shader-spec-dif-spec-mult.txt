(docs/app/shader-specs/dif-spec-mult.md), ETS2 1.60.1.7

Clean-room note (D13): the game's shaders were read only to learn the maths. All extracted
text was kept outside the repository, in the session scratchpad. This file lists what was
read and the non-shader data cited. It contains no shader text.

Commands (Git Bash, from the repository root)
  export ETS2_DIR="D:/Steam Library/steamapps/common/Euro Truck Simulator 2" MSYS_NO_PATHCONV=1
  cargo build --release -j 2 -p specsheet-research --example scs --example model_info --example uv_routing_survey
  scs cat effect/eut2/<dir>/<effect>.rfx            effect -> passes -> shader objects (glsl technique only)
  scs cat effect/eut2/_shd/<hash>.glsl.vso|fso      shader objects; printable runs extracted in the scratchpad
  scs cat effect/deferred/rs/{decal_mult,forward_mult,decal_none,forward_none,attrib_render}.rs
  scs cat effect/def/{flavors,inputs,uniforms,vas,eut2_interfaces}.sui
  Fragment and vertex main bodies were normalised (temporaries renamed) and diffed pairwise.

How each fact was established
  - Base vs dif.spec: forward 5cc81527 vs ebc9efa9, and G-buffer 3360427a vs 8e789a42. The only
    differences: a second 2D texture (texture_mult) sampled on the second interpolated UV pair
    and multiplied into the base sample (all four channels); the specular mask is the product's
    alpha without the remap; the forward output alpha is vertex alpha.
  - add.env vs dif.spec.add.env: forward 896dc697 vs 44df0b82, G-buffer d005974f vs c4956540.
    Same as above, plus the reflection strength multiplied by texture_mult alpha.
  - tsnmap (62b7723d) and tsnmapuv (c69b604a, e9e12b2d): the normal decode constants and fn
    factor of dif-spec §5.2 were read again; tsnmap samples the normal map on the base UV,
    tsnmapuv on the UV 6 stream.
  - iamod (960c9584, 7ebb0853): third texture on UV 2, lerped to white by vertex alpha, multiplied
    into the product; output alpha constant 1.
  - UV slots: vertex objects 5de0bdc0, 01140507, 0647d886, f414854a, f4794824 (texcoord 0/1/2/6
    attribute inputs), and the effect interface table: eut2.dif.spec.mult.dif.spec = colour,
    normal, position, texcoord0, texcoord1; .add.env.tsnmapuv adds tangent, texcoord6;
    .iamod.dif.spec.tsnmapuv adds texcoord2 and texcoord6; eut2.dif.spec.decal.mult = texcoord0.
  - paint: eut2.dif.spec.mult.dif.spec.paint and .add.env.paint name the same objects as the
    non-paint effects.
  - dif.spec.decal.mult: same objects as eut2.dif.spec.decal (decalpost 204cf578/f8d91ca6,
    decal 3e01f28b/ebc9efa9); state decal_mult.rs = decal_none.rs plus blend src dst_color,
    dst zero. forward_mult.rs: depth greater, no write, back cull, same blend.
  - Flavor table: flavor "mult" adds a white-fog fragment define ("add": a black-fog one).
  - Material-input table: mult_uvscale and mult_uvscale_secondary exist (default (1,1)); no
    material uniform lists them as inputs, and none of the objects above references them.
