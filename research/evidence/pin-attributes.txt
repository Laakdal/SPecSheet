3. Which game files set these keys (all .sii under /def, 1.60.1.7)
------------------------------------------------------------------
Searched every unit under /def for pin_group and
use_non_wheel_pin_data_from_model:
  - /def/truck_config_scene.sii (ui_truck_scene_config): the 65 entries in
    pin-table.txt.
  - /def/trailer_adjust_scene.sii (ui_truck_scene_config): the trailer's own
    pin table.
  - /def/vehicle/truck/renault.t/data.sii and renault.etech_t/data.sii
    (accessory_truck_data): one entry each, pin_group f_light_top.
  - No file sets use_non_wheel_pin_data_from_model, so every truck runs on its
    default (value Unknown; the name says non-wheel pins can take their data
    from "the model").

4. Code that creates pin buttons
--------------------------------
The pin button templates btn.custom_accn and btn.custom_accs exist as strings
(n/s presumably normal/selected). The pin_look values
acc_hub, acc_cover and acc_nuts do not occur in the executable, so the code
probably builds "btn." + look + "n"/"s" at run time (Hypothesis).
A scan of .text for RIP-relative references, with containing functions from
.pdata, gives:
  btn.custom_accn  referenced at 0x140fcd0bd in FUN_140fcce14 (855 bytes)
  btn.custom_accs  referenced at 0x140fcd0cd in FUN_140fcce14
                   and at 0x140fbd350 in FUN_140fbd120 (794 bytes)
  /def/trailer_adjust_scene.sii  at 0x140fb8ab4 in FUN_140fb8930
(.pdata gives chunk starts; FUN_140fcce14 is a chunk of FUN_140fccdb0.)
