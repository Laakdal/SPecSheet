Truck paint vertex streams: UV sets and vertex colours (truckpaint material)
==========================================================================

Command (ETS2 1.60.1.7, install opened read-only):
  ETS2_DIR=<game> cargo run --release -p specsheet-data --example paint_uv_survey

Every piece of every /vehicle/truck .pmd whose first-look material has a
truckpaint effect, by effect, number of PMG UV sets and colour stream.
Columns: pieces, models, uv sets, has colours, effect, first model.

Readings recorded in docs/app/materials.md:
- Mask UV: counting UV sets from 0 (mask set 1, altuv set 2), 393 of 1725
  paint pieces lack the set; with mask set 0 and altuv set 1, only 1 does.
  Liveries line up on cabs where the readings differ: the MAN TGX Euro 6
  cab_xl (tsnmapuv.airbrush.altuv, 2 sets) and the Actros 2014 (3 sets).
- Every paint piece has a colour stream; the mean is grey 0.326 (x2 = 0.65),
  and only 464 of 2.8M vertices have r, g, b more than 2 apart.
