# Implementation checklist

Rules behind each item: [standards/engineering.md](../standards/engineering.md), [standards/testing.md](../standards/testing.md).

- [ ] Goal and definition of done restated; open questions asked or assumptions stated
- [ ] Relevant code, callers and tests read before editing
- [ ] Failing test written first for new behaviour or the bug
- [ ] Change kept to the requested scope
- [ ] Tests, lint and build run; summary lines quoted
- [ ] Docs updated in the same change
- [ ] Report lists what changed, what was skipped, what is uncertain
